02 / PROJECTS

Software, pipelines and research platforms.

Open computational tools designed to make structural and molecular discovery more scalable and reproducible.

AM2PM
Research Platform
Anti-Microbial Perpetual Prospection Machine — an automated framework integrating metabolic network analysis, target identification, structural modeling, virtual screening and machine-learning-based consensus scoring.
ProtCHOIR
Structural Biology
A computational tool for proteome-scale generation and analysis of homo-oligomeric protein structures.
OCDocker
Machine Learning
A consensus docking framework combining multiple scoring functions with machine learning to improve the prioritization of protein–ligand complexes.
TARDIS
Systems Biology
Automated metabolic-network reconstruction and analysis for microbial systems, supporting the identification of potential therapeutic targets.
